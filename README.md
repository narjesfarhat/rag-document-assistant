## Introduction
Rag Document Assistant is a tool designed to help users create, manage, and collaborate on documents efficiently. This project aims to streamline the document creation process and enhance productivity.

## Installation
To install Rag Document Assistant, follow these steps:

```bash
# Clone the repository
git clone https://github.com/narjesfarhat/rag-document-assistant.git

# Navigate into the directory
cd rag-document-assistant

# Install dependencies
npm install
```

## Usage
To use the Rag Document Assistant, execute the following command:

```bash
node app.js
```
